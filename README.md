# 🎯 Price Hunter

Охотник за ценовыми ошибками и резкими падениями цен на Wildberries и Ozon —
независимый мониторинг обеих выдач, отдельная история цен по каждой площадке
на SQLite, скоринг аномалий, мгновенные алерты в Telegram и веб-панель находок.

➡ **Код, запуск для Windows и вся документация: [`price-hunter/`](price-hunter/README.md)**

**Приложение для Windows:** скачай готовый `PriceHunter.exe` в
**Actions → Build Windows app → Artifacts → PriceHunter-Windows**
(или из исходников: `price-hunter\run_desktop.bat`).

Веб-панель из исходников:
```bat
cd price-hunter
run.bat
```
http://127.0.0.1:8000

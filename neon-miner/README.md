# ◈ NeonMiner — клиент, куда вписываешь кошелёк и на него капает XMR

Локальный клиент для **CPU-майнинга Monero (XMR)**. Вбиваешь свой адрес →
выбираешь пул → получаешь готовый `config.json` для [XMRig](https://github.com/xmrig/xmrig)
→ запускаешь у себя → панель показывает баланс, хэшрейт и историю выплат.

**Ноль зависимостей**: только стандартная библиотека Python 3.9+. Работает на
Windows / Linux / macOS. Майнер не пишется с нуля — используется официальный
открытый XMRig, проверяемый по SHA256.

## 🪙 Кошелёк — создай за 10 секунд (офлайн)

**[→ Открыть `dist/NeonMiner-wallet.html`](dist/NeonMiner-wallet.html)** ·
[исходники](windows/web/wallet_crypto.js) · [тесты](tests/test_wallet.py)

Без XMR-адреса майнить некуда. Это **один автономный HTML-файл**, который генерирует
настоящий Monero-кошелёк у тебя в браузере. В нём стоит CSP `default-src 'none'`
и `connect-src 'none'` — сетевых запросов нет физически, ключи не покидают страницу.

1. Скачай файл и открой двойным кликом. Можно вообще отключить интернет.
2. Дождись зелёного статуса «ОФЛАЙН · 8/8 проверок пройдено» (иначе генерация заблокирована).
3. Нажми «🎲 Создать кошелёк». **Запиши 25 слов на бумагу** — это твои деньги.
4. Вставь полученный адрес в NeonMiner (поле «Твой Monero (XMR) адрес»).
5. Внизу страницы есть проверка: введи свои 25 слов и убедись, что адрес совпал.

Формат полностью стандартный — Keccak-256, ed25519, `sc_reduce32`, Monero Base58,
официальный wordlist на 1626 слов и CRC32-контрольное слово. Сид восстанавливается в
Monero GUI / Cake Wallet / Feather / Monerujo. Криптография сверена с исходниками
`monero-project/monero` и независимым пакетом `monero`: тест-вектор
`25 × "plus" → 44bUDLb1Fb8W…87C6VR` совпадает побайтово (оба приватных ключа,
оба публичных ключа и адрес). Плюс 71 автотест, включая сравнение `scalarMultBase`
с Node WebCrypto Ed25519 и проверку адресов нашим Python-валидатором.

> Ни в коем случае не присылай сид-фразу мне или в чат: кто её знает — владеет монетами.
> Не используй депозитный адрес биржи.

Пересобрать страницу: `python3 windows/build_wallet.py` (wordlist лежит в
`windows/wordlist_en.json`, взятом из `src/mnemonics/english.h` официального репозитория).

## 🪟 Готовый .exe для Windows

**[→ Скачать `dist/NeonMiner.exe`](dist/NeonMiner.exe)** · [инструкция](dist/README-Windows.md) · [SHA256SUMS.txt](dist/SHA256SUMS.txt)

Один файл **327 КБ**, Windows 10/11 x86-64, без Python и без установки. Двойной клик →
открывается браузер с неоновой панелью на `127.0.0.1:8765` (порт подберётся сам, если
занят). Вставляешь адрес → галочка согласия → **«▶ Начать майнинг»**. Дальше exe сам
скачивает официальный XMRig v6.26.0 с GitHub, сверяет SHA256 с `SHA256SUMS` релиза,
собирает `config.json` под твой кошелёк и запускает майнер. Всё лежит в
`%LOCALAPPDATA%\NeonMiner\`. Есть кнопка «Стоп», живой лог, дашборд, калькулятор.

Собран кросс-компиляцией из [`windows/neonminer.c`](windows/neonminer.c) через
`zig cc -target x86_64-windows-gnu`; HTML/CSS/JS, каталог пулов и демо-данные зашиты
внутрь. Сборка **воспроизводима**: два последовательных `build_windows.py` дают
одинаковый SHA256. Исходники открыты, подписи EV-сертификатом нет — поэтому
SmartScreen будет ругаться; сверяй хэш из `SHA256SUMS.txt`.

Пересобрать: `python3 windows/build_windows.py` (сам поставит `ziglang` с pypi.org,
соберёт Linux-близнеца и прогонит 10 внутренних проверок).

> В превью Arena крутится Linux-близнец exe для проверки интерфейса — там майнер
> **симулирован** и помечен жёлтой плашкой. В Windows-версии всё по-настоящему.

---

> **Честно про границы.** Клиент майнит только на машине, где его запустили
> вручную. Никакого скрытого майнинга на посетителях сайта, чужих серверах,
> «бесплатных» PaaS и т.п. — это криптоджекинг, и мы его не делаем.
> Если хочешь виджет «майни на моём сайте», то только с явным добровольным opt-in
> согласием каждого посетителя и видимой кнопкой «стоп» — такого в этом
> модуле нет намеренно.

## 🚀 Быстрый старт

```bash
cd neon-miner
./run.sh                 # Linux/macOS  (или run.bat на Windows)
```

Открой **http://127.0.0.1:8000**. В превью Arena сервер слушает `0.0.0.0`:

```bash
HOST=0.0.0.0 PORT=8000 python3 -m neon_miner serve --host 0.0.0.0 --port 8000
```

Дальше 4 шага в интерфейсе:

1. **Кошелёк** — вставь XMR-адрес. Панель проверит контрольную сумму Keccak
   (не длину, а именно чексумму): одна опечатка = монеты уйдут в никуда.
2. **Пул** — выбери, куда майнить. По умолчанию стоит C3Pool: у него самый
   низкий порог выплаты, то есть «капать» начнёт раньше всего.
3. **Настройки воркера** — имя, процент CPU, donate-level, порт.
4. **Собрать конфиг** — появляется `config.json`, команда запуска, systemd-юнит
   и `.bat`. Кнопкой «Скачать config.json» сохраняешь файл рядом с XMRig.

Запуск в одну команду (клиент сам скачает официальный XMRig и проверит SHA256):

```bash
python3 -m neon_miner start --wallet ТВОЙ_XMR_АДРЕС --pool c3pool --download
```

Без `--download` укажи `--binary /путь/к/xmrig`. Флаг `--dry-run` всё подготовит,
но не запустит процесс. Перед запуском CLI спрашивает подтверждение, что это
твоя машина (`--yes` пропускает вопрос в интерактивных скриптах).

### Где взять кошелёк

Нужен **свой** Monero-кошелёк, где есть приватные ключи. Не депозитный адрес
биржи: пулы часто не платят на интегрированные адреса, а биржа может не
зачислить майнинг-перевод.

- [Monero GUI / CLI](https://www.getmonero.org/downloads/) — официальный;
- [Cake Wallet](https://cakewallet.com/) — iOS/Android/Desktop;
- [Feather Wallet](https://featherwallet.org/) — лёгкий десктопный;
- [Monerujo](https://www.monerujo.io/) — Android;
- аппаратные: Ledger / Trezor через официальный GUI.

Адрес выглядит как 95 символов и начинается с `4` (основной) или `8`
(субадрес). 106 символов = интегрированный адрес, его лучше не использовать.

## ⛏ Где майнить: что я проверил

Монета выбрана **Monero (XMR)**: алгоритм RandomX заточен под обычные CPU,
видеокарта и ASIC не нужны. Майнинг идёт в пул, пул платит прямо на твой адрес —
никаких аккаунтов, KYC и «выводов» с биржи.

Все четыре пула ниже проверены **живыми запросами к их API 26.10.2026**: комиссии,
пороги, хосты, порты и форматы статистики. Исходники — в `neon_miner/pools.py`,
прямые ссылки на API в поле `sources`.

| Пул | Комиссия | Мин. выплата | Автопорог | Stratum | Почему |
|---|---|---|---|---|---|
| **C3Pool** ★ | 0% | **0.001 XMR** | 0.005 XMR | `auto.c3pool.org:13333`, TLS `mine.c3pool.com:33333` | Первая выплата при 5 kH/s уже через ~3 дня. Лучший «капельный» вариант |
| **HashVault** | 0.9% | 0.001 XMR | 0.11 XMR | `pool.hashvault.pro:443` (TLS) | Узел во Франкфурте, самый подробный API, цена XMR в EUR/RUB. Резервный домен `pool.hashvault.sh` |
| **MoneroOcean** | 0% | 0.003 XMR | 0.3 XMR | `gulf.moneroocean.stream:10128`, TLS `:20128` | Авто-переключение на самый выгодный RandomX-коин, платит XMR |
| **SupportXMR** | 0.6% | 0.1 XMR (вручную) | 0.3 XMR | `pool.supportxmr.com:3333`, TLS `:443` | Крупнейший и самый стабильный, но до выплаты при 5 kH/s — годы |

Источники параметров:

[C3Pool /pool/ports](https://api.c3pool.com/pool/ports) ·
[C3Pool setup script](https://github.com/C3Pool/xmrig_setup/blob/master/setup_c3pool_miner.sh) ·
[HashVault /pool/stats](https://api.hashvault.pro/v3/monero/pool/stats) ·
[HashVault /pool/ports](https://api.hashvault.pro/v3/monero/pool/ports) ·
[SupportXMR /config](https://www.supportxmr.com/api/config) ·

[MoneroOcean /config](https://api.moneroocean.stream/config) ·
[MiningPoolStats: SupportXMR](https://miningpoolstats.net/pools/supportxmr/) ·
[CoinBureau: лучшие пулы 2026](https://coinbureau.com/mining/best-monero-pools) ·
[2Miners API docs](https://github.com/2miners/apidoc) ·
[Monero: официальное руководство по майнингу](https://www.getmonero.org/get-started/mining/).

**Что не вошло и почему:** `xmr.2miners.com` сейчас отдаёт 404 и отсутствует в
[актуальном списке серверов 2Miners](https://github.com/2miners/apidoc/blob/master/2miners_api.json) —
подключать мёртвый эндпоинт нельзя. [P2Pool](https://p2pool.io/) — отличная
децентрализованная альтернатива с 0% комиссией и выплатой прямо в coinbase, но
требует собственной полной ноды (~100+ ГБ) и не имеет API баланса, поэтому в
клиент не включён; это следующий шаг, когда захочешь уйти от кастодиальных пулов.

### Как деньги доходят до кошелька

```
XMRig (твой CPU) ──stratum──> пул ──шары──> баланс пула ──достиг порога──> tx на твой адрес
                                                  ▲
                                     дашборд читает /api/miner/<адрес>/stats
```

Панель **не держит** твои монеты и не знает приватных ключей. Она только читает
публичную статистику пула по адресу и генерирует конфиг. PPLNS означает, что
баланс растёт неравномерно — это нормально.

## 💶 Экономика без обмана

Формула: `твой_хэшрейт / хэшрейт_сети × 720 блоков × награда × (1 − комиссия)`.

На 26.10.2026 сеть ≈ 6.88 GH/s, награда ≈ 0.608 XMR, цена ≈ 530 €. Тогда
**5 kH/s дают ≈ 0.00032 XMR/сутки ≈ 0.17 €/сутки**. Компьютер на 65 Вт при
0.36 €/кВт·ч съедает ≈ 0.56 €/сутки.

**Итого: примерно −0.39 €/сутки.** Встроенный калькулятор считает это сам и
показывает минус, а не «доходность». Считай майнинг экспериментом/поддержкой
сети, а не заработком. В Германии дополнительно уточни налоговый учёт добычи
(это доход; я не налоговый консультант) и подставь свою цену кВт·ч из счёта.

## 🔐 Безопасность и честность

- **Только официальный XMRig.** `start --download` тянет последний релиз из
  `github.com/xmrig/xmrig/releases/latest`, скачивает `SHA256SUMS` того же
  релиза, сверяет хэш и **только потом** распаковывает. Не совпало — архив
  удаляется, ничего не запускается. Ссылка: [релизы XMRig](https://github.com/xmrig/xmrig/releases).
- **Никакой скрытности.** В конфиге `background: false`, CPU ограничен 75% по
  умолчанию, HTTP-API XMRig слушает `127.0.0.1` в read-only режиме. Юнит для
  systemd отдаётся текстом, но **не устанавливается** автоматически.
- **SSRF закрыт.** Бэкенд ходит только по URL из жёстко заданного каталога
  пулов; произвольные адреса с фронтенда отклоняются (есть тест).
- **Проверка адреса.** Полный Monero Base58 + Keccak-256 checksum на чистом
  Python. Тестовые векторы Keccak сверены с эталоном.
- **Кошелёк** сохраняется только в `localStorage` твоего браузера (галочка
  «запомнить», кнопка «забыть»), в логах сервера query-строка обрезается.
- **Антивирусы** часто помечают XMRig как «майнер/PUA» — это ожидаемо.
  Сверяй хэш и не качай билды из телеграм-каналов и левых зеркал.

### Частые вопросы

**Можно ли запустить это на бесплатном Render/Oracle?** Нет. Это нарушает их
ToS (постоянная 100% нагрузка CPU), аккаунт банят, а 1–2 vCPU принесут копейки.
Doss-инфраструктура в этом репозитории — для VPN, не для майнинга.

**Можно ли встроить майнер в сайт-портфолио, чтобы майнили посетители?** Нет,
это криптоджекинг. Только явное добровольное согласие, видимый статус и кнопка
остановки — и всё равно браузерный WASM-майнинг в разы медленнее нативного.

**Почему баланс не растёт сразу?** PPLNS + созревание награды: шары созревают 30–60 блоков.
Первые 10–30 минут статистика может быть пустой.

**Почему выбрал не SupportXMR, он же крупнее?** Потому что ты попросил, «чтобы
капала монетка». При 0.3 XMR автовыплаты и 5 kH/s ждать ~2.5 года. C3Pool и
HashVault с порогом 0.001 XMR платят в первые дни. Переключиться можно в один
клик — баланс на каждом пуле независимый, поэтому лучше выбрать один и не прыгать.

## 🧰 CLI

```bash
python3 -m neon_miner                          # веб-клиент
python3 -m neon_miner pools                    # каталог пулов
python3 -m neon_miner check <адрес>             # проверка чексуммы
python3 -m neon_miner config --wallet <адрес> --pool hashvault --out config.json
python3 -m neon_miner start --wallet <адрес> --download --dry-run
python3 -m neon_miner profit --hashrate 5000 --watts 65 --kwh 0.36
```

## 🧪 Тесты

```bash
cd neon-miner
python3 -m unittest discover -s tests -v     # 49 тестов, сеть не нужна
# или
make test
```

Покрыто: Keccak-256 (эталонные векторы), валидация адресов, каталог пулов,
нормализация всех четырёх форматов API, генерация конфигов (TLS/failover/fixed
difficulty/санитайзинг воркера), калькулятор, HTTP-роуты и живой сервер,
защита от path traversal / SSRF / слишком больших запросов.

## 📁 Структура

```
neon-miner/
├── neon_miner/
│   ├── keccak.py       # Keccak-256 на чистом Python
│   ├── address.py      # Monero Base58 + проверка контрольной суммы
│   ├── pools.py        # проверенный каталог пулов (API, порты, комиссии)
│   ├── adapters.py     # нормализация ответов nodejs_pool / hashvault
│   ├── http_client.py  # urllib + кэш + белый список URL + демо-режим
│   ├── calc.py         # честный калькулятор доходности
│   ├── configgen.py    # config.json, CLI, systemd, .bat
│   ├── downloader.py   # официальный XMRig + проверка SHA256
│   ├── server.py       # HTTP API на ThreadingHTTPServer
│   ├── __main__.py     # CLI
│   ├── fixtures/       # синтетические демо-данные по форматам реальных API
│   └── static/         # неоновая панель (HTML/CSS/JS, без CDN)
├── tests/              # 49 unittest-тестов
├── run.sh / run.bat
└── README.md
```

Демо-режим: если API пула недоступен (офлайн/песочница), панель показывает
**явно помеченные вымышленные данные** — interface можно потрогать сразу. Как
только введён валидный адрес, фронтенд стучится в пул напрямую из браузера, а
бэкенд остаётся запасным каналом.

Прежде чем майнить
  • Только своё железо. Скрытый майнинг на чужих устройствах и посетителях сайта — криптоджекинг, мы такое не делаем.
  • Не майни на бесплатных VPS/PaaS (Render, Oracle Free): это нарушает ToS и приводит к бану.
  • Не используй адрес биржи — нужен свой кошелёк с приватными ключами.
  • Антивирусы ругаются на XMRig: качай только официальный релиз и проверяй SHA256.

Запуск в один шаг официальный XMRig

Клиент скачает XMRig с github.com/xmrig/xmrig, сверит SHA256 с SHA256SUMS релиза и только потом запустит. Без проверки — ни одного запуска.

python3 -m neon_miner start --wallet ТВОЙ_АДРЕС --pool c3pool --download --yes

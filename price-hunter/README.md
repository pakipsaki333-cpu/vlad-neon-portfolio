# 🎯 Price Hunter — охотник за ценовыми ошибками Wildberries

Монитор, который круглосуточно сканирует выдачу WB, ведёт собственную историю цен
и присылает **мгновенный алерт в Telegram**, когда товар резко дешевеет:
продавец уронил цену под самовыкуп, ошибся на порядок, сбросил остатки и т.д.
Тебе остаётся нажать «Купить» — такие цены живут минуты.

> **Ozon — этап 2.** У Ozon жёсткий антибот (куки браузерной сессии, 403 без них),
> поэтому старт — WB с открытым API. Заготовка клиента: `app/ozon_client.py`.

---

## Как он отличает настоящую ошибку от фейковой «скидки −90%»

На WB половина карточек кричит «−85%» круглый год — продавец просто раздувает цену
«до». Детектор (`app/detector.py`) смотрит не на наклейку, а на совокупность сигналов:

| Сигнал | Что означает |
|---|---|
| 📉 Падение vs медианы истории (своя база SQLite + WB `price-history.json`) | Главный сигнал. Самовыкуп/сброс виден даже при обычной наклейке |
| 🏷 Скидка по карточке `priceU → salePriceU` | Необходима, но **не достаточна** |
| 💸 Абсолютная выгода в ₽ | −90% на товаре за 300 ₽ — шум, отсекается |
| ⭐ Отзывы/рейтинг | Живой ликвидный товар, а не карточка-пустышка |
| ⚠ Штраф за фейк | Если история говорит «эта цена — обычная», скор режется и алерт не уходит |

Итоговый **скор 0–100**: `🔥🔥 FIRE ≥70` (вероятная ошибка — действуй немедленно),
`🔥 HOT ≥50`, `👀 WATCH ≥35`. Каждая находка сохраняется со снапшотом-доказательством
(цена, время, история) — пригодится, если будешь спорить с поддержкой по отменённому заказу.

**Важно про точность:** детектор умнеет со временем. Первые часы своя история пуста,
он опирается на WB price-history; через сутки мониторинга ложных срабатываний заметно меньше.

## Запуск на Windows (твой случай)

1. Поставь **Python 3.11+** с [python.org](https://www.python.org/downloads/),
   при установке отметь **«Add python.exe to PATH»**.
2. Скачай/склонируй проект, открой папку `price-hunter`.
3. Двойной клик по **`run.bat`** — сам создаст окружение, поставит зависимости
   и откроет панель: http://127.0.0.1:8000
4. Не закрывай чёрное окно, пока идёт охота. Остановка — `Ctrl+C`.

Linux/macOS: `bash run.sh`. Вручную: `pip install -r requirements.txt && uvicorn app.main:app --port 8000`

## Telegram-алерты за 2 минуты

1. В Telegram: **@BotFather** → `/newbot` → имя → получи **токен** (`123456:AA…`).
2. Открой своего бота, нажми **/start** (без этого бот не может тебе писать).
3. Узнай **chat id**: напиши **@userinfobot** — он пришлёт твой `Id`.
4. В панели: **⚙️ Настройки** → токен + chat id → **💾 Сохранить** → **✈️ Тест Telegram**.

Или через файл: скопируй `.env.example` в `.env` и заполни `TELEGRAM_TOKEN` / `TELEGRAM_CHAT_ID`.

## Настройки охоты (⚙️ в панели)

- **Запросы** — что сканируем. Ставь ликвид: то, что легко перепродать на Авито или нужно самому
  (электроника, брендовые кроссовки, LEGO, парфюм…). 16 запросов стоят по умолчанию.
- **Интервал** — по умолчанию 180 с. Минимум 60 с специально зашит: чаще = WB начнёт троттлить IP (429).
- **Мин. скидка / мин. падение vs истории / мин. выгода** — пороги детектора.
  По умолчанию: 65% / 35% / 1 000 ₽. Много шума → подними мин. выгоду до 3 000 ₽ и скор.
- **Режим** — `live` (только настоящий WB), `auto` (живой WB; если недоступен —
  временный demo и повторная проверка каждые 300 с), `demo` (**симуляция:
  настоящие товары не ищутся**).
- **Транспорт WB** — оставь `auto`: обычный HTTP, а при антибот-ответах 403/498 —
  браузерный транспорт curl_cffi (Chrome). Пауза между запросами по умолчанию 1,2 с.
- Регион WB (`dest`) — по умолчанию Москва (−1257786).

## Когда прилетел алерт ⏱

1. Открывай ссылку **сразу** — счёт на минуты, остатки у таких цен обычно 1–5 шт.
2. Проверь перед оплатой: размер/комплектацию/цвет (дёшево часто один размер), продавца и срок доставки.
3. Оплачивай WB Кошельком/картой сразу при заказе — при оплате при получении продавец проще отменит.
4. Скриншот заказа + наша фиксация в панели («История цены») — твои аргументы в споре.

⚠ Честные ограничения: WB/продавец **могут отменить** заказ по ошибке цены («технический сбой»),
части заказов это коснётся — это часть игры, а не гарантия халявы. Автовыкупа здесь нет сознательно:
он требует токен аккаунта и привязанную карту и ведёт к бану аккаунта; алерт+клик — безопасный путь.

## Режимы live / auto / demo и проверка WB

- **live** — настоящие запросы к витринным JSON WB (поиск v18/v9, карточка v4,
  история цен), без аккаунта и токенов. Если WB не отвечает — увидишь ошибку, а не тишину.
- **auto** — сначала live. Если WB недоступен, приложение временно показывает demo
  и **само перепроверяет live каждые 300 с** (настраивается), а на главном экране
  пишет точную причину: заблокировал антибот, 429, нет сети, пустой ответ и т.д.
- **demo** — симуляция каталога со случайными «ошибками» для проверки интерфейса и
  Telegram. **В demo настоящие товары не ищутся.** Если Telegram в demo работает,
  а товаров нет — почти наверняка режим остался demo или auto ушёл в fallback.

**«В demo всё работает, но товары не ищет» — что нажать:**

1. Вкладка **Настройки → Режим → `live`** (для проверки честнее, чем auto),
   **Транспорт WB → `auto`**.
2. Кнопка **«Сохранить и проверить WB»** (или «Проверить соединение WB» на главной).
3. Читай вердикт: `ok` + пример товара = живой поиск работает, дальше просто жди
   аномальных падений (обычные товары пишутся в базу без алертов);
   `blocked` = антибот WB (отключи VPN/прокси, другая сеть, открой WB в браузере);
   `rate_limited` = увеличь паузу/интервал; `network_error` = интернет/DNS/VPN.
4. Полный JSON диагностики пишется в `wb-diagnostics.json` в папке данных
   (`%APPDATA%\PriceHunter` у exe) — его можно прислать при разборе проблемы.
   Из исходников та же проверка: `check_wb.bat` или `python desktop_app.py --diagnose-wb`.

## Структура

```
app/
  wb_client.py   # витринные JSON WB: search v18→v9→v5→v4, карточка v4, диагностика
  basket.py      # хосты basket-XX (таблица из cdn.wbbasket.ru/api/v3/upstreams)
  detector.py    # скоринг аномалий, отсев фейковых скидок
  scanner.py     # фоновый цикл опроса, дедуп алертов, fallback
  db.py          # SQLite: товары, снапшоты цен, алерты, журнал запусков
  telegram.py    # Bot API: алерт с фото, тест
  config.py      # настройки (settings.json + .env; папка данных — PRICE_HUNTER_DATA_DIR)
  demo.py        # генератор демо-данных
  ozon_client.py # этап 2 (заготовка)
  main.py        # FastAPI + веб-панель
desktop/
  gui.py         # окно Tkinter: Главная / Находки / Настройки / Журнал, тосты
  controller.py  # валидация формы настроек, обёртка над движком (без GUI-зависимостей)
  tray.py        # иконка в трее (pystray, опционально), уведомления
  autostart.py   # автозапуск с Windows (HKCU\...\Run)
desktop_app.py   # точка входа приложения (--minimized / --self-test / --diagnose-wb / --gui-smoke)
check_wb.bat     # проверка доступности WB из исходников (пишет wb-diagnostics.json)
PriceHunter.spec # PyInstaller: один windowed PriceHunter.exe без веб-стека
build_windows.bat / run_desktop.bat  # сборка exe / запуск приложения из исходников
assets/icon.ico  # иконка приложения
static/index.html  # веб-дашборд: лента находок, графики истории, настройки
tests/             # python -m unittest discover -s tests -v
.github/workflows/build-windows.yml  # CI: тесты + сборка exe в артефакты
```

API: `GET /api/status|alerts|products|runs`, `GET /api/product/{nm}/history`,
`POST /api/scan/start|stop|now`, `POST /api/wb/diagnose`, `GET|POST /api/settings`,
`POST /api/telegram/test`.

## Проблемы?

| Симптом | Причина / лечение |
|---|---|
| В DEMO всё работает и Telegram подключён, но товары не ищет | Так и задумано в demo — это симуляция. Настройки → Режим `live`, Транспорт `auto` → «Сохранить и проверить WB» |
| Проверка WB: `blocked` (403/498) | Антибот WB: отключи VPN/прокси, попробуй домашнюю/мобильную сеть, открой wildberries.ru в браузере, затем повтори проверку |
| Панель в DEMO на домашнем ПК при режиме auto | WB не ответил — смотри красную строку причины на главной и вердикт «Проверить WB»; live перепроверяется автоматически каждые 300 с |
| Проверка WB `ok`, а находок нет | Поиск работает: обычные товары копятся в базе без алертов; алерт бывает только на аномальное падение. Глянь «Товаров в базе» и журнал |
| Telegram: тест не проходит | Не нажал /start у бота; неверный chat id; опечатка в токене |
| Ни одной находки за час | Норма: ошибки редки. Расширь запросы, снизь мин. падение до 30% |
| Много шума | Подними мин. выгоду и мин. скидку; дай базе сутки накопить историю |
| Ошибка 429 в журнале | WB троттлит: увеличь интервал до 300 с, уменьши страниц на запрос |

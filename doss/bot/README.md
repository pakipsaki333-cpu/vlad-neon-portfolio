# Telegram-бот Doss

Рабочий бот на **aiogram 3**: триал, подписка за Telegram Stars, выдача ссылки,
автоистечение. Никаких логов трафика — в базе только tg-id, срок и лимит.

```
bot/
├── dossbot/
│   ├── bot.py          хэндлеры, инвойсы Stars, админ-команды
│   ├── service.py      бизнес-логика: триал, продление, истечение
│   ├── providers.py    demo / local / ssh — как дотянуться до CLI doss
│   ├── db.py           SQLite: users, payments
│   └── config.py       переменные окружения / .env
└── tests/
    ├── selftest.py           26 проверок логики (без aiogram и сети)
    └── test_provider_cli.py  10 проверок интеграции с реальным CLI doss
```

## Установка на сервере

```bash
sudo ./deploy/install-all.sh     # ставит всё, включая бота
sudo doss-set-token              # единственный шаг: вставить токен
```

Дальше бот обновляется только через `/start` → `/whoami` → `/grant <id> inf`.

## Запуск вручную (для разработки)

```bash
cd doss/bot
cp .env.example .env                    # вписать BOT_TOKEN и OWNER_ID
python3 -m venv .venv
./.venv/bin/pip install -r requirements.txt
./.venv/bin/python -m dossbot
```

`BOT_TOKEN` — у [@BotFather](https://t.me/BotFather). `OWNER_ID` можно не заполнять:
**владельцем становится тот, кто первым отправил `/start`** (сохраняется в БД).
На сервере это делает за тебя `sudo doss-set-token`, затем `/whoami` покажет твой id.

## Что умеет

| Команда | Действие |
|---|---|
| `/start` | меню: триал, подписка, моя ссылка, инструкция |
| `/trial` | 3 дня / 10 ГБ, один раз на аккаунт, без карты |
| `/buy` | инвойс в Stars (`XTR`), продление на 30 дней |
| `/me` | срок, лимит, `vless://`-ссылка |
| `/help` | как подключить Hiddify / v2rayNG |
| `/support` | связь с владельцем |
| `/whoami` | твой tg_id (пригодится для `/grant`) |
| `/stats` | (владелец) пользователи, платежи, суммы |
| `/grant <tg_id> <дней\|inf>` | (владелец) выдать доступ вручную |

Платёж идемпотентен по `telegram_payment_charge_id` — повторное событие не
продлевает подписку дважды. Если сервер недоступен при оплате, владельцу
приходит уведомление, а пользователю — «напиши /support» (деньги не теряются).

## Три способа дотянуться до сервера

| `PROVIDER` | Как работает | Когда |
|---|---|---|
| `demo` | ссылки-заглушки, ничего не создаёт | посмотреть UI, тесты |
| `local` | `doss …` локально | всё на одном сервере |
| `ssh` | `ssh doss@vpn doss …` | бот на отдельной машине |

Прод-вариант (`ssh`): ключ бота прописан в `authorized_keys` с forced command
[`../deploy/doss-ssh`](../deploy/doss-ssh) — по этому ключу можно вызвать **только**
`doss`, shell и порт-форвардинг запрещены. Проверяется тестом: `cat /etc/shadow`
через такой ключ вернёт «запрещено».

## Данные

```sql
users(tg_id PK, username, doss_name UNIQUE, status, trial_used,
      expires_at, traffic_gb, created_at, updated_at)
payments(id PK, tg_id, amount, currency, days, created_at)
```

Специально **не храним**: IP, историю подключений, посещённые сайты, телефоны.
Это и политика конфиденциальности, и лучшая защита от претензий.

## Оплата: почему Stars

- не нужен эквайринг, ИП и модерация;
- нет чарджбэков;
- работает из РФ без карты, вывод на Fragment.

Цена по умолчанию — 150 ⭐ (≈ 119 ₽). Меняется одной переменной `STARS_PRICE`.
Крипта (USDT/TON) — следующий шаг: там нужна ручная сверка или провайдер
(Crypto Pay API), это отдельная итерация.

## Проверки

```bash
python3 tests/selftest.py          # логика: триал, продления, истечение, статистика
python3 tests/test_provider_cli.py # реальный CLI: state.json меняется как надо
```

Telegram-часть (инвойсы и вебхуки Stars) проверяется только на живом боте —
первый платёж прогони на себе за 1 ⭐-тестовую цену, потом ставь рабочую.

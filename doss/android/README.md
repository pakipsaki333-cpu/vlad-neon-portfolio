# Android-клиент Doss — как сделать правильно

Честно: писать VPN-клиент с нуля — это 3–6 месяцев и постоянные баги с
IPv6/MTU/роумингом. Готовый туннель уже есть в открытых проектах под GPL-3,
поэтому правильный путь — **форк**, где мы меняем брендинг, онбординг и биллинг,
но не трогаем ядро туннеля.

## Что форкать

| Проект | Стек | Плюсы для нас | Минусы |
|---|---|---|---|
| **Hiddify-app** (34k★) | Flutter + sing-box | подписки, REALITY, XHTTP, Hysteria2, автотест профилей, все платформы | Flutter, крупная кодовая база |
| **Amnezia-client** (15k★) | Qt/C++ | AmneziaWG из коробки, self-hosted философия | тяжёлый UI-стек, слабее по XHTTP |
| v2rayNG | Kotlin/Java | простой, близко к «нативному Android» | только Xray, без AWG, старый UI |

Рекомендация: **Hiddify-app**. Тогда `vless://`-ссылки из бота работают сразу,
а нам остаётся брендинг + подписка + пресеты.

## Пошагово

```bash
# 1. форк и клон
gh repo fork hiddify/hiddify-app --clone
cd hiddify-app

# 2. ветка Doss
git checkout -b doss-branding

# 3. зависимости
flutter --version          # >= 3.24
flutter pub get

# 4. запуск на устройстве
flutter run --flavor doss  # если флаворов нет — flutter run
```

### Чек-лист изменений

- [ ] **Название и иконка**: `android/app/src/main/AndroidManifest.xml`
      (`android:label`), `assets/images/`, `pubspec.yaml` (`name` менять не нужно).
- [ ] **Цвета**: тема приложения → тёмный фон `#07070C`, акцент `#8B5CF6`/`#22D3EE`
      (совпадает с панелью).
- [ ] **Онбординг**: первый экран — «У меня есть ключ Doss» + кнопка «Вставить ссылку»
      и «Открыть Telegram». Второй — инструкция «включить туннель».
- [ ] **Стартовая подписка**: в настройках подписок подставить
      `https://vpn.example.com/s/<token>` — но токен персональный, поэтому
      правильнее: deep-link `doss://sub?token=...`, который бот присылает кнопкой.
- [ ] **Deep link**: `intent-filter` на `doss://` + `vless://`;
      обработчик: `doss://sub?url=<encoded>` → добавить подписку и обновить.
- [ ] **Убрать лишние локации/серверы** из дефолтных пресетов, оставить наш узел.
- [ ] **Отключить телеметрию/аналитику** (в Hiddify есть opt-in — оставить только opt-in).
- [ ] **Подпись**: свой keystore, `key.properties`, `flutter build apk --release --split-per-abi`.

### Публикация

- **Telegram-канал + APK** — самый быстрый путь, без модерации.
- **Google Play**: VPN-приложения разрешены, но нужна декларация `VpnService`
  и политика конфиденциальности; в РФ магазин может ограничить показ.
- **RuStore** — проще, но требует документов.
- GPL-3: исходники форка обязаны быть открыты, лицензия и копирайт — сохранены
  (ссылку на upstream в «О приложении»).

## Что можно не форкать

До 500 пользователей хватает связки «бот + Hiddify/v2rayNG из стора»:
пользователь получает ссылку и импортирует её за 15 секунд. Свой клиент нужен,
когда важны бренд, оплата в один тап и удержание, а не сама функциональность.

## Оценка работ (для планирования)

| Этап | Время |
|---|---|
| форк, сборка, запуск на устройстве | 1–2 дня |
| брендинг, онбординг, deep-link подписки | 3–5 дней |
| оплата внутри приложения (Telegram Stars / крипта / карта) | 3–7 дней |
| подпись, релиз в канал, автообновление | 1 день |
| Play-модерация и политика конфиденциальности | 1–2 недели ожидания |

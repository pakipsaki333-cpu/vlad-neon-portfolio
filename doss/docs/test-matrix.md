# Матрица тестов Doss — заполняется с реальных сетей

Методика: с Android-телефона в каждой сети подключаемся по очереди каждым
транспортом, держим 30 минут, замеряем скорость (fast.com) и стабильность.
Один тест = одна строка. Дата обязательна: ситуация меняется неделями.

## Что считать успехом

- **Поднялось** — страница `https://ifconfig.me` показала IP узла.
- **Стабильно 30 мин** — ни одного разрыва, YouTube 1080p без буферизации.
- Минимально приемлемо: ≥ 20 Мбит/с на мобильном, ≥ 50 Мбит/с на домашнем.

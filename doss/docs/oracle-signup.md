# Oracle Cloud Always Free: пошагово, без сюрпризов

Это единственный способ получить **бесплатный навсегда** сервер, который тянет
VPN. Ниже — точный порядок, чтобы не потерять час на «Out of host capacity»
и не получить списание.

## 0. Что подготовить заранее

- **Карта** Visa/Mastercard (не «Мир», не виртуальная одноразовая). Спишут и сразу
  вернут ~1 € для проверки. Российские карты не подходят — нужна зарубежная
  (Kaspi, монгольская, казахстанская, Revolut и т.п.).
- **Телефон** для SMS.
- **E-mail**, к которому есть доступ.
- Спокойные 20 минут.

## 1. Регистрация — где ошибаются чаще всего

1. https://signup.cloud.oracle.com → страна: **Germany** (или Netherlands).
   ⚠️ **Home region выбирается здесь и потом не меняется.** Германия/Нидерланды —
   оптимальный пинг в европейскую часть РФ. США брать не надо: +100 мс и трафик через океан.
2. Тип аккаунта: **Individual** (не Company) — меньше вопросов.
3. Подтверждение карты: спишут ~1 € и вернут. Если банк отклоняет — попробуй другую карту,
   это самая частая причина провала.
4. После регистрации сразу **не** переходи на Pay As You Go: бесплатного хватает,
   а PAYG иногда снимает деньги за «превышения».

## 2. Создание инстанса

Консоль → **Compute → Instances → Create instance**.

| Поле | Значение |
|---|---|
| Name | `doss-vpn` |
| Image | **Canonical Ubuntu 24.04** (не Oracle Linux — меньше мороки с iptables) |
| Shape | **Ampere → VM.Standard.A1.Flex** |
| OCPUs | **2** |
| Memory | **12 GB** |
| Boot volume | 50 GB (в пределах 200 GB бесплатных) |
| SSH keys | **сгенерировать свою пару** и скачать приватный ключ |
| Public IP | Assign a public IPv4 address ✅ |

Нажми **Create**. Если видишь `Out of host capacity` — это норма:

```bash
# на своём компьютере, с установленным OCI CLI (oci setup config)
./server/oracle-hunt.sh --compartment <ocid> --subnet <ocid> --ssh-key ~/.ssh/id_ed25519.pub
```

Скрипт сам перебирает availability domains и пишет IP в `~/.doss-server-ip`.

## 3. Открыть порты (иначе VPN «не работает», а вы будете искать баг в Xray)

Два места, оба обязательны:

1. **Security List**: Networking → VCN → Security Lists → Default →
   Add Ingress Rule: source `0.0.0.0/0`, protocol **TCP**, port **443**
   (+ **8443**, если ставите XHTTP; + **UDP 51820**, если ставите AmneziaWG).
2. **Локальный файрвол** — установщик Doss делает это сам
   (`iptables` в образах Oracle по умолчанию всё режет).

## 4. Установка Doss

```bash
ssh -i ~/.ssh/id_ed25519 ubuntu@<IP>

# на сервере:
sudo -i
git clone <репозиторий> /opt/doss     # или распакуй doss-bundle.tar.gz
/opt/doss/doss/deploy/install-all.sh
```

Дальше — единственный шаг с твоим участием:

```bash
sudo doss-set-token     # вставить токен от @BotFather
```

## 5. Что нельзя забыть (иначе сервер заберут)

Oracle может **отобрать инстанс**, если 7 дней подряд CPU, сеть и память ниже 20 %.
Установщик ставит таймер `doss-keepalive` (каждые 30 минут), проверка:

```bash
systemctl list-timers | grep doss
sudo doss-doctor
```

Плюс: 18 августа 2026 Oracle уже **терминировал** инстансы сверх лимита
2 OCPU / 12 GB. Не расширяй shape «на всякий случай».

## 6. Когда бесплатного станет мало

- 10 TB/мес общего трафика хватает ~200–300 активным пользователям.
- Второй узел — не второй Oracle-аккаунт (за это банят), а дешёвый VPS:
  Hetzner CX23 ≈ 6 €/мес или Contabo. Правило: **два провайдера, две страны**.
- Деньги на резерв берутся из подписки: 6 платящих по 119 ₽ закрывают узел.

## Частые ошибки

| Симптом | Причина |
|---|---|
| `Out of host capacity` | нет свободной ARM-ёмкости → `oracle-hunt.sh` или ждать ночи |
| Сайт открывается, VPN — нет | порт 443 не открыт в Security List |
| Работает 2 минуты и рвётся | заблокирован UDP/QUIC у оператора → переключить профиль на XHTTP |
| Через 2 недели «сервер исчез» | idle reclamation → проверь таймер keepalive |
| Списание 0.5–1 € | превышен бесплатный лимит (второй инстанс / лишний диск) |
| Карта не принимается | нужна зарубежная карта, «Мир» не поддерживается |

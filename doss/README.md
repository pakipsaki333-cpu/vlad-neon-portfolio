# Doss — свой VPN: бесплатный сервер, символическая подписка

> Статус: **серверная часть готова** (VLESS+REALITY, мультиюзер, срок действия,
> анти-idle для Oracle). Клиент для Android и Telegram-бот — следующие шаги,
> см. [roadmap](#roadmap). Тесты CLI: `bash server/tests/test_cli.sh` → 26/26.

Doss — это не ещё один «бесплатный VPN-клиент», а собственная инфраструктура:

- **сервер** — на бесплатном Oracle Cloud Always Free (2 ARM-ядра, 12 ГБ, 10 ТБ/мес);
- **протокол** — VLESS + REALITY (+ XHTTP и AmneziaWG как резерв), см. [docs/protocols.md](docs/protocols.md);
- **выдача доступа** — CLI `doss` на сервере, потом Telegram-бот поверх него;
- **деньги** — бесплатно для тебя и своих, ~119 ₽/мес для остальных; этой суммы
  хватает на резервный платный узел (см. [экономику](#экономика)).

## 1. Где взять сервер бесплатно

Полный разбор с подводными камнями: **[docs/free-servers.md](docs/free-servers.md)**.
Коротко:

| Вариант | Что дают | Годится? |
|---|---|---|
| **Oracle Cloud Always Free** | 2 OCPU ARM / 12 GB / 10 TB egress, навсегда | ✅ основной узел |
| Google Cloud e2-micro | 1 vCPU / 1 GB, 3 региона США, ~1 GB egress | ⚠️ только под бота, не под трафик |
| AWS / Azure / DigitalOcean / Vultr | кредиты на 30–180 дней | ❌ не навсегда |
| Публичные «free VLESS» подписки | чужие сервера | ❌ приватность |

Два ограничения Oracle, о которых нужно знать заранее:

1. **Регион фиксируется навсегда** при регистрации → выбирай Frankfurt/Amsterdam.
2. **ARM-ёмкость часто кончается** (`Out of host capacity`) → [`server/oracle-hunt.sh`](server/oracle-hunt.sh)
   перебирает availability domains, пока не создаст инстанс, и пишет IP в `~/.doss-server-ip`.
3. **Idle reclamation** → установщик ставит таймер анти-idle (`--no-keepalive`, чтобы выключить).

## 2. Установка на свежий Ubuntu 22.04/24.04 (x86_64, arm64)

```bash
git clone <repo> && cd doss/server

sudo ./install.sh \
  --dest www.microsoft.com \
  --with-xhttp \
  --owner vlad
```

Что произойдёт:

1. поставится Xray (официальный установщик, fallback — релиз с GitHub);
2. сгенерируются ключи REALITY и `short_id`-ы;
3. поднимется VLESS+REALITY на `443/tcp` (+ XHTTP на `8443/tcp`);
4. откроется порт в локальном файрволе (не забудь **Security List** в Oracle!);
5. включится BBR и анти-idle таймер;
6. создастся пользователь `vlad` (`unlimited`) и ежедневный `doss tick` для истечения подписок.

В конце установщик напечатает готовую ссылку `vless://…` и QR.

> **Не открывай ссылки и QR в публичных каналах.** Это первый признак для сканеров
> и причина, по которой узлы «умирают за сутки».

### Выбор маски REALITY

`--dest` — сайт, под который маскируемся. Требования: TLS 1.3, не заблокирован в РФ,
не Cloudflare, крупный и стабильный. Проверенные варианты: `www.microsoft.com`,
`www.samsung.com`, `swift.com`, `www.lovelive-anime.jp`. Проверяй с российской сети:
`curl -I https://<домен>` и `openssl s_client -connect <домен>:443 -tls1_3`.

## 3. Управление пользователями

```bash
doss user add anna --expires 2026-12-31 --traffic 200   # символическая подписка
doss user add mama --unlimited --note "семья"           # бесплатно, без лимитов
doss user list
doss link anna        # vless:// для Reality
doss qr anna          # QR прямо в терминале
doss sub anna --url-base http://<ip>   # файл-подписка + URL
doss user set anna --disable           # приостановить
doss user rm anna                      # отозвать (uuid + short_id удаляются из конфига)
doss status
```

Состояние — один файл `/etc/doss/state.json` (ключи, пользователи, сроки).
Конфиг Xray собирается из него (`doss rebuild`), перед применением прогоняется
`xray -test`. Поэтому ручной правки `config.json` не требуется и она бесполезна —
она перезапишется.

**Подписки по HTTP** (необязательно). Файлы лежат в `/var/www/doss-sub/<token>.txt`,
токен — 32 случайных байта. Если хочешь отдавать их по URL, поставь nginx:

```nginx
server {
    listen 80;
    server_name sub.example.com;
    root /var/www/doss-sub;
    location ~ ^/sub/([0-9a-f]{32})\.txt$ { try_files /$1.txt =404; default_type text/plain; }
    location / { return 404; }
}
```

Для MVP проще вообще без HTTP: бот присылает ссылку прямо в чат.

## 4. Клиенты для Android (сегодня)

Свой клиент — это месяцы работы и модерация в сторах. Начать можно бесплатно:

| Клиент | REALITY | XHTTP | AWG | Замечание |
|---|---|---|---|---|
| **Hiddify** | ✅ | ✅ | ⚠️ | лучший выбор «всё в одном», есть подписки |
| **v2rayNG** | ✅ | ✅ | ❌ | классика, простой |
| **Happ** | ✅ | ✅ | ❌ | удобный импорт по ссылке |
| **Amnezia VPN** | ✅ | ⚠️ | ✅ | открытый код (GPL), можно форкнуть под Doss |

Своё приложение (этап 3) разумно делать как форк **Hiddify-app** или **Amnezia-client**
(GPL-3 — значит и твой форк должен быть открытым). Тогда 90 % работы — это
брендинг, онбординг и биллинг, а не туннель. Писать VPN «с нуля» на Kotlin
с `VpnService` + VLESS-стеком — это 3–6 месяцев и постоянные баги с IPv6/MTU.

## 5. Экономика

| Статья | Стоимость |
|---|---|
| Oracle ARM Always Free (10 ТБ) | 0 € |
| Домен + страница подписки | ~10 €/год |
| Резервный узел Hetzner CX23 (2 vCPU/4 ГБ/20 ТБ) | ~6 €/мес |
| **Итого фикс** | **≈ 6–7 €/мес** |

- **Ты и «свои»** — `unlimited`, 0 ₽.
- **Остальные** — 119 ₽/мес, софт-лимит 200–300 ГБ; триал 10 ГБ / 3 дня.
- 6 платящих закрывают резервный узел целиком, дальше — второй узел/локация.
- Честно про лимиты: 10 ТБ Oracle — общий котёл. Один торрент-юзер выжирает узел
  и получает abuse-жалобу → узел сносят. Поэтому bittorrent заблокирован в конфиге,
  а лимиты обязательны.

## 6. Легальные и операционные риски (по-честному)

- В РФ **запрещена реклама VPN** и «популяризация обхода»; штрафы для
  распространяющих. Продажи «в лоб» через российские площадки — плохая идея.
- Апрель 2026: законопроект «Антифрод 2.0» ограничивает размещение VPN у
  хостинг-провайдеров. Отсюда правило: **узлы только вне РФ, минимум два провайдера**.
- Google Play требует декларации `VpnService` и ограничивает VPN-приложения;
  в RuStore/Telegram-канале — проще. Поэтому MVP = бот + готовые клиенты.
- Ты находишься в ЕС: если хранишь e-mail/платежи — это уже персональные данные
  (GDPR). Минимизируй: Telegram-id + срок подписки, без логов трафика и без
  «истории подключений». Логи трафика не пишем вообще — и это надо указать в оферте.
- Никакой поддержки торрентов и «серых» схем — это то, за что узлы и аккаунты
  в облаках блокируют.

## Известные ограничения

- Установщик и конфиги **не прогонялись против живого Xray** (в песочнице нет
  доступа к релизам GitHub и нет root) — синтаксис скриптов проверен, схема
  конфига соответствует Xray 24.9+; первый запуск делай на тестовой машине.
- `awg-setup.sh` зависит от PPA Amnezia; на arm64 сборок может не быть — в скрипте
  есть инструкция по сборке userspace-демона.
- Учёт трафика по пользователям пока не реализован: лимиты — «на честном слове»
  + блокировка bittorrent. Для реальных лимитов нужен Xray API (`statsquery`).

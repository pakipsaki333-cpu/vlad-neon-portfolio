# Doss на бесплатном хостинге — без карты, за 10 минут

Этот режим нужен, когда **нет карты** и нет сервера, а VPN хочется сегодня.
Работает на Render.com (free, карта не требуется), архитектурно — VLESS поверх
**WebSocket**: платформа сама даёт HTTPS-домен, TLS делает она, внутри контейнера
Xray слушает выданный порт.

```
клиент ──wss://doss-ws.onrender.com/doss-ws──► Render (TLS) ──► xray (WS) ──► интернет
```

## Что получается

| Параметр | Значение |
|---|---|
| Цена | **0 ₽**, карта не нужна |
| Трафик | 5 ГБ/мес на сервис |
| Ресурсы | 512 МБ RAM, 0.1 CPU, 750 часов/мес |
| Простой | сервис засыпает через 15 минут без трафика, просыпается ~30–60 сек |
| Клиенты | любые: Hiddify, v2rayNG, Happ, Streisand (ws+tls) |
| Пользователей | фактически 1–3 (одна ссылка на всех) |

Честно: это **не продакшн**. 5 ГБ в месяц — это ~2 часа YouTube в 720p.
Для «проверить, что всё работает» и «пользоваться самому» — отлично; для
сервиса на людей — нужен VPS за 250–600 ₽, который можно оплатить по СБП
без карты (см. [`../../docs/no-card.md`](../../docs/no-card.md)).

## Вариант A. Blueprint (оба сервиса сразу)

1. Зарегистрируйся на https://render.com через GitHub (карта не нужна).
2. **New → Blueprint** → выбери репозиторий `pakipsaki333-cpu/vlad-neon-portfolio`,
   ветку `main`. Render прочитает `render.yaml` и предложит два сервиса:
   `doss-ws` (VPN) и `doss-bot` (бот).
3. Apply. Первая сборка ~3–5 минут.
4. Открой `doss-ws` → **Logs**. В логах будет блок:

```
 Домен   : doss-ws-xxxx.onrender.com
 ССЫЛКА ДЛЯ КЛИЕНТА (скопируй целиком):
vless://<uuid>@doss-ws-xxxx.onrender.com:443?encryption=none&security=tls&type=ws&path=%2Fdoss-ws&sni=...&fp=chrome#Doss%20WS
```

5. Скопируй ссылку → Hiddify → «+» → «Импорт из буфера» → подключиться.
   Первый коннект после простоя — до минуты (сервис просыпается).
6. Для бота: `doss-bot` → Environment → впиши `BOT_TOKEN` (у @BotFather) и
   `DOSS_LINK` (ссылку из п.4) → Save (сервис перезапустится сам).

## Вариант B. Вручную, только VPN (если blueprint не хочется)

1. **New → Web Service** → **Public Git repository** →
   `https://github.com/pakipsaki333-cpu/vlad-neon-portfolio`
2. Runtime: **Docker**. Dockerfile Path: `doss/deploy/paas/Dockerfile`,
   Docker Context: `doss/deploy/paas`.
3. Instance Type: **Free**. Region: **Frankfurt**.
4. Environment:
   - `DOSS_PATH=/doss-ws`
   - (опционально) `DOSS_UUID=<свой uuid>` — тогда ссылка не изменится никогда
5. Create → дождаться `Live` → взять ссылку из логов.

## Важно про UUID

UUID — это и есть твой пароль. Он **выводится стабильно** из `RENDER_SERVICE_ID`
(внутренний id сервиса), поэтому переживает рестарты и пересборки.
Если хочешь свою ссылку навсегда и независимо от Render — задай `DOSS_UUID`
(любой uuid v4) в Environment.

Чтобы **отозвать доступ** — поменяй `DOSS_UUID`, сервис пересоберётся,
старая ссылка умрёт.

## Проверка локально (без Docker и без Render)

```bash
cd doss/deploy/paas
DOSS_PRINT_CONFIG=1 PORT=10000 DOSS_UUID=11111111-2222-4333-8444-555555555555 ./entrypoint.sh | jq .
DOSS_DRY_RUN=1 PORT=8080 RENDER_EXTERNAL_HOSTNAME=demo.onrender.com ./entrypoint.sh
```

`DOSS_PRINT_CONFIG=1` печатает готовый конфиг Xray (его можно скормить
`xray -test`), `DOSS_DRY_RUN=1` — печатает ссылку и не запускает туннель.

## Риски, о которых надо знать

- **ToS**: бесплатные PaaS не любят постоянный прокси-трафик. Для личного
  использования в разумных объёмах — обычно терпимо, но гарантий нет:
  сервис могут ограничить. Не строй на этом продажу подписок.
- **5 ГБ трафика** — общий на сервис, считается весь исходящий.
- **Сон**: после 15 минут простоя соединение рвётся, клиент переподключается,
  первый пакет ждёт ~минуту. В Hiddify включи авто-переподключение.
- **WebSocket+tls** виден DPI лучше, чем REALITY: в мобильных сетях РФ может
  резаться чаще. Это аварийный/тестовый канал, а не «неубиваемый».
- Бот в режиме `PROVIDER=link` выдаёт **одну ссылку всем**: лимиты и сроки
  в нём — декоративные (он честно пишет об этом в `/me`).
